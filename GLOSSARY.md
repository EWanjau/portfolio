# Portfolio

The context for Erasto Wanjau's data-science portfolio, living in this repository. It exists to convince hiring managers to interview him.

## Language

**Portfolio Site**:
The public site presenting Erasto's work to hiring managers — analytics-led, mixing analysis case studies with end-to-end ML.
_Avoid_: website, homepage, personal site

**Case Study**:
A written page about one Project, structured as problem, approach, and measurable outcome, with visuals.
_Avoid_: project page, demo, write-up

**Project**:
The underlying code or analysis a Case Study presents, typically a GitHub repository.
_Avoid_: portfolio piece

**Writing**:
Articles Erasto publishes on his dev.to blog (dev.to/erasto), distinct from Case Studies written for the Portfolio Site.
_Avoid_: blog posts, articles
